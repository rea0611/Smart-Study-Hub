🚀 Smart Study Hub – AI-Driven Intelligent Learning Assistant
A Python + Gradio based intelligent study companion that transforms raw notes into structured, scientifically optimized learning material.

🔖 Overview
Smart Study Hub is a browser-based learning assistant designed to help students study smarter—not harder.
Given PDF or text notes, the system automatically generates:
Flashcards
Pomodoro study cycles
Feynman explain-it-yourself prompts
Active Recall pages
MCQ quizzes
Weak-area analysis
Personalized dashboard
The entire experience is wrapped in a clean, calming user interface powered by Gradio.

🏆 Key Features
📘 1. Notes Upload
Upload notes in PDF or text format.

✂ 2. Notes Extraction Engine
Extracts text cleanly
Identifies definitions & keywords
Prepares conceptual chunks

🧠 3. Multiple Study Techniques
Flashcards Generator
Pomodoro Study Timer
Feynman Technique
Active Recall Pagination
Spaced Repetition Suggestions

📝 4. Auto MCQ Quiz Generator
Creates MCQs from extracted notes
Provides scoring & analytics
Detects weak areas

📊 5. Personalized Dashboard
Tracks:
Total attempts
Average score
Best score
Weak topics
Last studied technique

🔁 6. Resume System
Continue from exactly where you left off.

💾 7. Lightweight CSV Storage
No heavy database—just plug and run.

🛠️ Tech Stack
Python 3.10+
Gradio (UI framework)
PyPDF2 (PDF processing)
Regex-based NLP
CSV for data persistence

🔍 How It Works (Short Explanation)
User uploads PDF/text
System extracts text
Notes are chunked and processed
Selected study technique transforms the text
Dashboard logs user performance
Resume system saves state

🎯 Why Gradio?
Lightning-fast development
No front-end coding required
Browser-based & minimal setup
Highly modular (Blocks API)
Perfect for AI + education applications
